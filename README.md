# Python CLI Choose Your Own Adventure Game

Hello! This is a Choose Your Own Adventure game built entirely in Python. 

This project was created as a piece of interactive fiction designed to encourage youth literacy. By gamifying the reading experience, it provides an engaging, interactive medium tailored specifically for younger audiences.

---

## 🛠️ Prerequisites

Before running the application, please ensure you have the latest version of [Python](https://www.python.org/) installed on your computer.

*No additional libraries are strictly required to play the game, but optional dependencies can be installed via `pip` or by running the setup file.*
```
pip install pygame

pip install numpy
```

---

## 🚀 Setup and Installation

Follow these steps to build and run the game:

1. Run the `Setup.py` file to compile the application.
2. Once the setup process completes, a new folder named `dist` will be created inside the main application directory.
3. Open the `dist` folder to find and run the executable file to start your adventure.

---

## 📁 File Structure

```text
Terminal-Choose-Your-Own-Adventure-Game-master/
├── Main.py       # The main entry point to start the game
├── Setup.py      # Script to handle installation and executable creation
└── story.py      # Contains the narrative branches and story data
```
