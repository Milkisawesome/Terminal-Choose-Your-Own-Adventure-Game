<h1>Python CLI Choose Your Own Adventure Game</h1>
<p>Hello! This is a choose your own adventure game made using python. 
This was created as a piece of interactive fiction in order to create and encourage the youth to read more by gamifying the experience and is aimed towards young audiences</p>
<br>

<h2>Pre-Requistes</h2>
<p>Please ensure that the latest version of <a href="https://www.python.org/">Python</a> is installed</p> on your computer for this application to run correctly.
Other extra libraries that are not required can be installed via pip or the Setup.py file.

<br>
<h2>Setup and Installation </h2>
<p>Please run the Setup.py file. Once the setup is completed in the a new folder will be created in the application folder called "dist",inside that folder will be the executable file to run the game.</p>

<br>
